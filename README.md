# 📚 My Library – Flask CRUD Book Manager

This is a straightforward web application developed using **Flask** and **SQLAlchemy**, enabling users to oversee a personal book collection. Users can **add**, **view**, **edit ratings**, and **delete** books that are saved in a local SQLite database.

This project effectively illustrates the fundamental CRUD (Create, Read, Update, Delete) operations in Flask, employing HTML templates.

---

## 🚀 Features

| Action      | Description                                                    |
|-------------|---------------------------------------------------------------|
| Add Book    | Generate a new book entry that includes the title, author, and rating |
| View Library| Present all saved books in alphabetical order                |
| Edit Rating | Modify the rating for any book that is stored                |
| Delete Book | Eliminate a book from the database                            |

---

## 🛠️ Technologies Used

- Python 3
- Flask (Web framework)
- SQLAlchemy ORM
- SQLite database
- HTML + Jinja templates
